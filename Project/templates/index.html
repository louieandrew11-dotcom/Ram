Cardiovascular Disease Prediction using Machine Learning

Cardiovascular disease (CVD) is the leading cause of death globally. Early diagnosis and timely intervention are crucial for preventing severe complications such as heart failure and myocardial infarction. This web application demonstrates how machine learning algorithms analyze patient clinical parameters to assess the risk of heart disease with high accuracy.

Get Started → Go Directly to Patient Prediction

Project Overview

This project is designed and implemented as an academic final-year / semester college project. It demonstrates the full lifecycle of a supervised machine learning workflow applied to healthcare diagnostics:

📊 1. Dataset Analysis

Explore clinical records containing 14 key physiological attributes (such as age, blood pressure, cholesterol, resting ECG). Upload new custom CSV datasets or analyze the benchmark Cleveland heart disease data.

View Dataset →

📈 2. Data Visualization

Inspect graphical distributions including age spread, chest pain correlations, heart rate trends, and a comprehensive correlation heatmap showing relationships between biometric variables.

View Graphs →

⚖️ 3. Model Comparison

Compare five widely used classification algorithms: Logistic Regression, K-Nearest Neighbors (KNN), Support Vector Machine (SVM), Decision Tree, and Random Forest on real test metrics (Accuracy, Precision, Recall, F1-Score).

Compare Models →

🧑‍⚕️ 4. Live Prediction

Input clinical data for any patient to receive an instant diagnosis prediction, calculated risk percentage, and actionable lifestyle recommendations based on the highest-performing machine learning model.

Test Prediction →

Key Project Features

  • Standard Machine Learning Pipeline: Built with Scikit-learn using StandardScaler feature scaling and stratified train-test splitting.
  • Real-time Model Training: All 5 algorithms are evaluated on actual data with confusion matrix calculation and classification metrics.
  • Dynamic Dataset Support: Flexibility to upload any custom heart disease CSV file and dynamically recalculate all metrics and visualizations.
  • Interactive Clinical Form: Includes pre-fill sample profiles (Healthy and High-Risk) for easy live demonstration during college project reviews.
